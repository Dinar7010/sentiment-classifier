# Sentiment Classifier — классификация тональности отзывов

Программный модуль для автоматической классификации тональности текстовых отзывов на русском языке (нейтральный / положительный / отрицательный) с использованием классических методов машинного обучения.

## Задача

На вход подаётся датасет с текстовыми отзывами. Для каждого отзыва модель должна определить класс тональности:
- `0` — нейтральный
- `1` — положительный
- `2` — отрицательный

## Данные

Используется [Russian Sentiment Dataset](https://www.kaggle.com/datasets/mar1mba/russian-sentiment-dataset) с Kaggle — 290 458 отзывов, собранных из 11 источников (отзывы на одежду, фильмы, аниме, банки, новости и др.).

**Важная оговорка:** официальное описание значений меток на странице датасета отсутствует. Соответствие классов 0/1/2 определено эмпирически, на основе анализа содержания текстов внутри каждого класса.

## Технологии

- Python
- pandas — обработка данных
- scikit-learn:
  - `TfidfVectorizer` — векторизация текста
  - `LinearSVC` — модель классификации
  - `train_test_split`, `accuracy_score`, `classification_report`, `confusion_matrix` — обучение и оценка
- matplotlib, seaborn — визуализация

## Как запустить

1. Скачать датасет с [Kaggle](https://www.kaggle.com/datasets/mar1mba/russian-sentiment-dataset), положить файл `sentiment_dataset.csv` в корень проекта
2. Установить зависимости:
```
pip install pandas scikit-learn matplotlib seaborn
```
3. Запустить:
```
python sentiment_classifier.py
```

## Ограничения

Датасет составлен из 11 разнородных источников (отзывы на одежду, фильмы, аниме, банковские услуги и т.д.), каждый со своей стилистикой текста. Часть отзывов содержит смешанную тональность (например, положительную оценку сервиса при негативной оценке товара в рамках одного текста), что ограничивает потолок точности для модели на основе TF-IDF, не учитывающей глубокий контекст.
